# NECC Home Assistant Apps

Repository til Niller Energy Command Center på Home Assistant / Raspberry Pi 5.

## Apps
- NECC P1 VAGT 1.0.2

## Installation i Home Assistant
1. Settings / Indstillinger -> Apps -> Install app
2. Tre prikker -> Repositories
3. Tilføj HTTPS-adressen til dette GitHub-repository
4. Genindlæs App-butikken
5. Installer **NECC P1 VAGT**

Der ligger ingen Home Assistant-token, adgangskoder eller andre hemmeligheder i repositoryet.
